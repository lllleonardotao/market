# 财小通 · 行情日报

当前行情页面的完整静态代码，包含盘前、盘中、盘后视图及自选内容。

## 本地预览

需要 Python 3 和 Node.js，无需安装依赖。

```sh
npm run dev
```

打开 http://localhost:4173 。

## 检查

```sh
npm run check
```

## 文件

- `dist/index.html`：页面结构
- `dist/styles.css`：页面样式
- `dist/app.js`：时段切换和页面交互
- `dist/assets/`：图片、图标和字体
- `DESIGN.md`：设计原则

页面行情与影响文案为设计演示数据。
